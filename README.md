# Paideia · Taejae Learning Suite

Landing page for the four apps of the Taejae Learning Suite, served by GitHub Pages:
https://jkwahk02.github.io/Paideia/

| App | Greek | Role | Link |
|---|---|---|---|
| Telos | τέλος · purpose | Advising and academic planning | https://jkwahk02.github.io/Telos/ |
| TaeSylla | σίλλυβος · course | Course design and syllabus | https://jkwahk02.github.io/TaeSyllaPro/ |
| Ergon | ἔργον · work | Student work and showrooms | https://jkwahk02.github.io/Ergon/ |
| Arete | ἀρετή · excellence | Learning outcomes assessment | Pilot, November 2026 |

> Purpose (Telos) guides a well-designed course (TaeSylla), and the course gives shape to the work (Ergon).
> Through that work excellence (Aretē) is revealed, and it fulfils its purpose (Telos).
